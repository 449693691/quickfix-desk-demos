# AI-assisted portrait background edit

A fresh demonstration using a fictional, AI-generated person. The park version was edited from the office input shown beside it.

| Generated input: home office | Edited version: park |

For a supplied-photo commission, we agree which details must remain unchanged and review a preview before final delivery. Scope, price and timing are agreed in advance.
